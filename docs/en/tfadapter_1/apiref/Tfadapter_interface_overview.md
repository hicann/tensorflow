# TF Adapter Interface Overview

## Overview

TF Adapter provides APIs for users to develop training or online inference scripts based on the deep learning framework TensorFlow 1.15.

**Figure  1**  TF Adapter APIs  
![](figures/TF-Adapter_interface.png)

API path: $\{TFPLUGIN_INSTALL_PATH\}/python/site-packages/npu_bridge.

## Supported Products

- Ascend 950PR&950DT products
- Atlas A3 products
- Atlas A2 products
- Atlas training products
- Atlas inference products (only online inference is supported)
